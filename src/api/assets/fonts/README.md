# Fonts

DejaVu Sans (Regular + Bold) — dùng để dựng PDF báo cáo SAR có dấu tiếng Việt.

Font Type1/TTF mặc định của trình dựng PDF (Helvetica) không phủ Latin Extended
Additional nên rớt dấu tiếng Việt. DejaVu Sans phủ đủ và có giấy phép tự do
(Bitstream Vera / DejaVu license — được nhúng, phân phối, sửa đổi).

Nguồn: gói matplotlib (mpl-data/fonts/ttf). Không phải phụ thuộc runtime — chỉ
là tài nguyên tĩnh nhúng vào ảnh api.
