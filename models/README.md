# FIN-07 model releases

## Mô hình nằm ở đâu — đọc trước

Console chấm điểm theo lối **tính sẵn**: mô hình chạy một lần ở ngoài, điểm nạp
vào `transaction_model_score`, API chỉ đọc bảng đó. **Máy chủ production không
giữ file mô hình nào và không nạp mô hình lúc chạy** — không có `joblib.load`
hay `torch.load` nào trong `src/api/`, `src/detection/`, `src/investigation/`.

Hệ quả: **thư mục này là bản gốc duy nhất.** PostgreSQL chỉ giữ mã băm SHA-256
(`edge_model_release.model_sha256`) để chứng minh điểm đang phục vụ do đúng file
này sinh ra. Mất file thì mã băm ấy không đối chiếu được với gì nữa.

Vì vậy: **trọng số mô hình phải được commit vào Git.** Chỉ điểm từng giao dịch
(`*.parquet`) mới để ngoài, vì chúng lớn và dựng lại được từ trọng số.


`fin07_if_graph_fusion_v1.joblib` is the canonical runtime bundle generated by:

```bash
python scripts/build_fusion_release.py
```

The bundle contains the frozen 7-day Isolation Forest and Graph
HistGradientBoosting estimators, train-only percentile calibrations, component
weights, the validation-selected threshold and source checksums. It preserves
the two detector contributions instead of replacing them with an opaque third
model.

Do not replace the binary manually. Update the source handoff checksum and
fusion config, rebuild the release, review `reports/fusion_release_v1.json`,
then publish a new version.

## Currency-native transaction model

`fin07_currency_native_policy_edge_v1.joblib` is the CPU transaction-scoring
release generated by `scripts/train_currency_native_edge.py`. It retains native
paid/received amounts and currencies, freezes train-only per-currency
normalization, and contains no static USD conversion. Its benchmark and MVP
contract are documented in `docs/ml/CURRENCY_NATIVE_EDGE_MVP.md`.
